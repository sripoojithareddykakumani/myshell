# MyShell

A custom Unix shell implemented in C as a systems programming project.

## Features

- Execute Linux/Unix commands
- Built-in `cd` command
- `exit` command
- Sequential command execution using `##`
- Parallel command execution using `&&`
- Output redirection using `>`
- Process creation and management

## Technologies

- C
- Linux
- GCC
- Unix System Calls

## Concepts Used

- `fork()`
- `execvp()`
- `wait()`
- Process management
- File descriptors
- I/O redirection
- Command parsing
